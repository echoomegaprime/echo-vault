# Support

## Community help

Use [GitHub Discussions](https://github.com/echoomegaprime/echo-vault/discussions) for deployment questions, design conversations, and usage help. Search existing discussions and documentation before opening a new topic.

Use [GitHub Issues](https://github.com/echoomegaprime/echo-vault/issues) for reproducible defects and focused feature proposals. Include the ECHO Vault version, deployment shape, expected behavior, actual behavior, and a minimal synthetic reproduction.

## Security reports

Do not disclose suspected vulnerabilities in Discussions or Issues. Follow [SECURITY.md](SECURITY.md) and use GitHub private vulnerability reporting. Never attach real keys, client manifests, databases, credentials, or decrypted values.

## Commercial support

Commercial deployment, integration, and operational support is available separately through [ECHO OMEGA PRIME](https://echo-op.com/). The public repository remains self-hostable and Apache-2.0 licensed.
